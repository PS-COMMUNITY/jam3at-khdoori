## 🔒 القواعد الذهبية (مختصر — التفصيل في 00-المنهجية)
1. **كل الأعمال محلياً** — يُمنع الرفع على المودل إلا بطلب صريح من الطالب
2. فحص المودل بحساب الطالب **قراءة فقط**
3. المتمم: Bearer مباشرة (القيمة في الخزنة) — لا DPoP ولا OAuth
4. عبر النفق متاح dl 0-1 فقط: `file_list` / `file_read_*` / `code_write_file` / `file_upload`
5. الثنائيات عبر النفق: رفع على x0.at ثم `file_upload` من URL إلى مسار الجهاز
