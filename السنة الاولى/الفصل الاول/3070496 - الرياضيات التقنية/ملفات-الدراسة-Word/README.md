## 🎯 أسلوب كل ملف (بناءً على طلب محمد):
1. **الشرح من الصفر** — لطلاب ما بفهموا شي بالرياضيات: كل رمز مشروح، تشبيهات حياتية، و«ليش؟» بعد كل خطوة.
2. **صندوق القوانين** — جدول كل ما يجب حفظه.
3. **مثال محلول خطوة بخطوة** — من أمثلة السبورة.
4. **أسلوب الشرح ثم الاختبار بسؤال:**
   - **السؤال 1** 🎓: نموذج محلول بالتفصيل الكامل — احفظ طريقة الحل منه.
   - **السؤال 2** ✍️: نفس الطريقة بأرقام مختلفة — طبّق وتأكد بالحل.
   - **السؤال 3** 🔥: جرب بنفسك أولاً — ثم قارن بالحل الكامل.
5. **صندوق المحفوظات** — آخر نظرة قبل الامتحان.
