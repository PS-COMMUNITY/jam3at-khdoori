## 🎯 السؤال الكبير: لما ن−∞... شو يصير بالحدود؟

نأخذ الحد النوني زₙ ونحرك ن للأمام بلا حدود (ن → ∞) ونلاحظ: **وين يمشي زₙ؟**

# التصنيفات الثلاثة (من السبورة — بالأحمر!):

| التصنيف | الشرط | المعنى |
|---------|-------|--------|
| **متقاربة** ✅ | ن→∞: زₙ → **عدد حقيقي** | الحدود تتقارب لعنوان ثابت |
| **متباعدة** ❌ | ن→∞: زₙ → **+∞ أو −∞** | الحدود تهرب للأعلى/الأسفل بلا توقف |
| **مذبذبة** ❌ | زₙ → **لا يوجد** (يتأرجح) | تقفز يمين يسار بلا قرار |

> 🏠 **تشبيه:** أنت تركض:
> - **متقاربة:** بتوصل لبيت محدد (عنوان: مثلاً 3 أو 0.5) وتقف عنده
> - **متباعدة:** تركض وتركيض بلا نهاية (تطير للسما ∞)
> - **مذبذبة:** يوم عند البيت ويوم بعيد، يوم موجب يوم سالب — عمرك ما تستقر!

---

## 🔧 الأداة الأساسية: نهايات الاقتران النسبي

أغلب الأسئلة = متتالية بصورة **كسرين: بسط فوق ومقام تحت** مع ن → ∞
**القاعدة: قارن درجة (أعلى قوة) البسط مع درجة المقام:**

| الحالة | النهاية | الحكم |
|--------|---------|-------|
| درجة البسط **أقل** من المقام | **0** | ✅ متقاربة |
| درجتان **متساويتان** | **نسبة المعاملات الرئيسية** | ✅ متقاربة |
| درجة البسط **أكبر** | **±∞** | ❌ متباعدة |

> ⚖️ **تشبيه:** سباق ن² ضد ن³: لما تصير الأرقام ضخمة، **القوة الأعلى تهيمن وتلتهم الباقي** — إذا تعادلوا بالدرجة، الحسم بين "معاملات السباق" (الأرقام اللي جنب أعلى قوة).

---

## ✏️ أمثلة محلولة (من السبورة 57 بالضبط!)

### مثال 1: زₙ = ن²
- ن→∞: ن² → **+∞** ← **متباعدة** ❌

### مثال 2: زₙ = (3ن + 1)/ن
- = 3 + 1/ن ← ن→∞: 1/ن → 0 ← النهاية **3**
- **متقاربة** ✅ (تقترب من العنوان 3)

### مثال 3 (درجات متساوية): زₙ = (3ن + 1)/(2ن + 1)
- درجة البسط = درجة المقام = 1 ← نسبة المعاملات = 3/2
- **متقاربة** ✅ (تقترب من 3/2 = 1.5)

### مثال 4 (درجتان متساويتان تانية): زₙ = (ن² + 3ن + 4)/(ن² + 4ن + 3)
- درجتا الاثنين = 2 ← نسبة معاملات ن² = 1/1 = **1**
- **متقاربة** ✅

### مثال 5 (بسط أقل): زₙ = (3ن + 1)/(ن² + 3)
- درجة البسط 1 < درجة المقام 2 ← النهاية **0**
- **متقاربة** ✅

### مثال 6 (تقسيم بالقسمة العليا — من السبورة): زₙ = (ن² + ن)/2 = ن²/2 + ن/2
- ن→∞: ن²/2 يسيطر → **∞** ← **متباعدة** ❌

### مثال 7 (متذبذبة): زₙ = (−1)ⁿ
- ن=1: −1 ، ن=2: +1 ، ن=3: −1 ... قفز بلا استقرار ← **مذبذبة** ❌ (لا يوجد نهاية)

---

## 📝 مسائل تدريب (حكم بسرعة!)

**1)** زₙ = (5ن)/(2ن + 1) ؟
**2)** زₙ = (ن³)/(ن² + 5) ؟
**3)** زₙ = 7/(ن + 2) ؟
**4)** زₙ = (−1)ⁿ · 2ن ؟
**5)** زₙ = (4ن² + 1)/(3ن² − 2) ؟

### ✅ الحلول:
1. درجتان متساويتان (1=1) ← نسبة المعاملات 5/2 ← **متقاربة (تقترب من 2.5)**
2. البسط 3 > المقام 2 ← ∞ ← **متباعدة**
3. بسط ثابت (درجة 0) < مقام (درجة 1) ← 0 ← **متقاربة (تقترب من 0)**
4. يكبر قياساً ويتأرجح إشارتاً ← لا نهاية ← **مذبذبة/متباعدة** (الأرجح بالمادة: مذبذبة)
5. درجتان متساويتان (2=2) ← 4/3 ← **متقاربة (تقترب من 4/3 ≈ 1.33)**

---

## 🧠 للمحفوظة (آخر درس — آخر فرصة!)
- **متقاربة:** زₙ → عدد حقيقي ✅
- **متباعدة:** زₙ → ±∞ ❌
- **مذبذبة:** لا يوجد نهاية ❌
- الاقتران النسبي: **بسط أقل → 0 | تساوي → نسبة المعاملات | بسط أكبر → ∞**
- تذكر (1/ن) → 0 عندما ن → ∞
