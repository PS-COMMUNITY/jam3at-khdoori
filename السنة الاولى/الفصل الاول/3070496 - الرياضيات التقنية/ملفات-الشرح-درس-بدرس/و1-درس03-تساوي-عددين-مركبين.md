# 🧸 درس 3: تساوي عددين مركبين

**الوحدة الأولى | قاعدة بسيطة جداً وبتيجي ضمن أسئلة كبيرة**

---

## 🎯 القاعدة

عددان مركبين **متساويان** إذا وفقط إذا:

# **حقيقي الأول = حقيقي الثاني**
# **وتخيلي الأول = تخيلي الثاني**

يعني لو: س₁ + ص₁ت = س₂ + ص₂ت
فإن: **س₁ = س₂** و **ص₁ = ص₂**

> 🧦 **تشبيه:** تشابه حيتين جوارب: لازم الجورب الأحمر مع الأحمر، والأزرق مع الأزرق. الحقيقي يطابق الحقيقي، والتخيلي يطابق التخيلي — **ما يخلطوا أبداً!**

## ⚠️ انتبه لحالة "معكوسة"
إذا عطوك: س + 2ت = 5 + صت
فحالاً: **س = 5** و **ص = 2** — طالعوا من المقالة نفسها!

---

## ✏️ أمثلة محلولة خطوة خطوة

### مثال 1: أوجد س وص إذا: (3س + 2) + (ص − 1)ت = 7 + 4ت
**الخطوة 1:** طابق الحقيقي مع الحقيقي:
- 3س + 2 = 7 ← 3س = 5 ← **س = 5/3**

**الخطوة 2:** طابق التخيلي مع التخيلي:
- ص − 1 = 4 ← **ص = 5**

### مثال 2: أوجد الحقيقيين إذا: (س + 2ت) = (4 + صت)
- س = **4**
- ص = **2**

### مثال 3: للعدد (س + صت) = (−3) فقط (عدد حقيقي نقي)
- ص = **0** (لأن التخيلي لازم يكون صفر)
- س = **−3**

### مثال 4 (نوع ييجي كثير): إذا (2س + صت) = (6 − 8ت) فأوجد س·ص
- س = 3 ، ص = −8 ← س·ص = **−24**

---

## 📝 مسائل تدريب

**1)** أوجد س وص: (س − 1) + (2ص)ت = 5 + 6ت
**2)** أوجد س وص: (4س) + (ص + 3)ت = −8 + ت
**3)** إذا س + صت = −9t فهو عدد تخيلي نقي، شو قيمة س؟
**4)** من المعادلة: (س² + 1) + (ص)ت = 10 → شو س وص إذا س موجب؟

### ✅ الحلول:
1. س − 1 = 5 ← **س = 6** ، 2ص = 6 ← **ص = 3**
2. 4س = −8 ← **س = −2** ، ص + 3 = 1 ← **ص = −2**
3. **س = 0** (لأن التخيلي النقي حقيقيه صفر)
4. س² + 1 = 10 ← س² = 9 ← **س = 3** (موجب) ، ص = **0**

---

## 🧠 للمحفوظة
- تساوي المركبة = تطابق **حقيقي مع حقيقي** + **تخيلي مع تخيلي**
- معادلة واحدة مركبة = **معادلتين حقيقيتين** مخفيتين!
