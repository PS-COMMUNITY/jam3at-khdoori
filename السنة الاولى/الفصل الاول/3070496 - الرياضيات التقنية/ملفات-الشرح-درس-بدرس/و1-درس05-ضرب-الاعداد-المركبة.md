# 🧸 درس 5: ضرب الأعداد المركبة

**الوحدة الأولى | توزيع عادي + تعويض ت² = −1 — بس هيك!**

---

## 🎯 القاعدة

# **وزّع زي أي ضرب، وكل ما يطلع ت² عوّضها بـ −1**

**(س₁ + ص₁ت)(س₂ + ص₂ت) = س₁س₂ + س₁ص₂ت + ص₁س₂ت + ص₁ص₂ت²**

ثم: ت² = −1 ← فالجزء الأخير يصير رقم **حقيقي سالب**!

> 🧩 **تشبيه:** مثل (س+2)(س+3) بالحقيقيين — نفس التوزيع بالظبط. الفرق الوحيد: في النهاية ت² تتحول لـ −1 فتضيف للجانب الحقيقي.

---

## ✏️ أمثلة محلولة خطوة خطوة

### مثال 1: (2 + 3ت)(1 − 4ت) = ؟
**خطوة 1 — وزّع:**
= 2 − 8ت + 3ت − 12ت²
**خطوة 2 — اجمع التخيلي وعوض ت²:**
= 2 + (−8+3)ت − 12(−1)
= 2 − 5ت + 12
**النتيجة: 14 − 5ت** ✅

### مثال 2: (1 + ت)² = ؟
= 1 + 2ت + ت² = 1 + 2ت − 1 = **2ت**
(ملاحظة حلوة: مربع (1+ت) تخيلي نقي!)

### مثال 3: (3 − 2ت)(3 + 2ت) = ؟
= 9 + 6ت − 6ت − 4ت² = 9 − 4(−1) = 9 + 4 = **13**
👀 **لاحظ:** التخيلي اختفى! هذا شكل مميز اسمه **مجموع مربعين** — راح يفيدنا بالقسمة (درس 7)

### مثال 4: (2ت)(5 − ت) = ؟
= 10ت − 2ت² = 10ت − 2(−1) = **2 + 10ت**

### مثال 5 (النوع الشائع): (−1 + ت)² + (1 − ت)² = ؟
- (−1+ت)² = 1 − 2ت + ت² = −2ت
- (1−ت)² = 1 − 2ت + ت² = −2ت
- المجموع = **−4ت**

## 📝 مسائل تدريب

**1)** (4 + ت)(2 + 3ت) = ؟
**2)** (5 − 2ت)² = ؟
**3)** (2 + ت)(2 − ت) = ؟
**4)** ت(1 + ت) = ؟
**5)** (1 + ت)(2 + ت)(3 + ت) = ؟ (نصيحة: ابدأ بأول اثنين)

### ✅ الحلول:
1. 8 + 12ت + 2ت + 3ت² = 8 + 14ت − 3 = **5 + 14ت**
2. 25 − 20ت + 4ت² = 25 − 20ت − 4 = **21 − 20ت**
3. 4 − ت² = 4 + 1 = **5**
4. ت + ت² = **−1 + ت**
5. (1+ت)(2+ت) = 2 + 3ت − 1 = 1 + 3ت ؛ ثم (1+3ت)(3+ت) = 3 + ت + 9ت + 3ت² = 3 + 10ت − 3 = **10ت**

## 🧠 للمحفوظة
- الضرب = توزيع + **ت² ← −1**
- (س+صت)(س−صت) = **س² + ص²** (لا مقياس مربع — بدون جذر!)
