# الجزء الأول: العدد المترافق 🔄

## 🎯 تعريفه

المرافق = نفس العدد لكن **نقلب إشارة الجزء التخيلي فقط**

# **ع = س + صت ⟸ المرافق: ع̄ = س − صت**

> 🔁 **تشبيه:** المرافق مثل "المرآة": تخيلي العدد بينعكس (موجب ← سالب / سالب ← موجب)، والحقيقي يظل ثابت مثل الحجر.

| العدد | مرافقه |
|-------|--------|
| 3 + 4ت | 3 − 4ت |
| −2 + ت | −2 − ت |
| 5 − 7ت | 5 + 7ت |
| 8 | 8 (بدون تخيلي = نفسه) |
| 3ت | −3ت |

## خواص سريعة:
- مرافق المرافق = العدد نفسه: (ع̄̄) = ع
- **ع × ع̄ = س² + ص² = |ع|²** ← نتيجة ذهبية (الضرب بمرافقه يعطي عدد حقيقي!)

# الجزء الثاني: المقياس 📏

## 🎯 تعريفه

المقياس = **المسافة من نقطة العدد إلى مركز المستوى** (الأصل)

# **|ع| = √(س² + ص²)**

> 🏠 **تشبيه:** أنت ببيتك (نقطة س، ص) وعندك محطة إطفاء بالمركز. المقياس = **طول الطريق المستقيم** من بيتك للمحطة (نظرية فيثاغورس!)

---

## ✏️ أمثلة محلولة خطوة خطوة

### مثال 1: أوجد مرافق ومقياس: 3 + 4ت
- المرافق: **3 − 4ت**
- المقياس: |3+4ت| = √(3² + 4²) = √(9+16) = √25 = **5**

### مثال 2: أوجد مرافق ومقياس: 1 − ت
- المرافق: **1 + ت**
- المقياس: √(1² + (−1)²) = √2

### مثال 3: أثبت أن: (2 + 3ت)(2 − 3ت) = |2 + 3ت|²
- يسار: 2² + 3² = 4 + 9 = 13
- يمين: |2+3ت|² = (√13)² = 13 ✔ متساويان!

### مثال 4: أوجد قيمة س إذا: |س + 3ت| = 5
- √(س² + 9) = 5 ← س² + 9 = 25 ← س² = 16 ← **س = ±4**

---

## 📝 مسائل تدريب

**1)** مرافق: −6 + 5ت ؟  **2)** المقياس: 5 + 12ت ؟  **3)** المقياس: −3ت ؟
**4)** (1 + ت)(1 − ت) = ؟  **5)** إذا |س + ت| = √10 فأوجد س

### ✅ الحلول:
1. **−6 − 5ت**
2. √(25+144) = √169 = **13**
3. √(0+9) = **3**
4. 1 + 1 = **2**
5. س² + 1 = 10 ← س² = 9 ← **س = ±3**

---

## 🧠 للمحفوظة
- المرافق: **اقلب إشارة التخيلي فقط**
- المقياس: **√(س²+ص²)** دايماً موجب
- **ع × ع̄ = |ع|² = س² + ص²** (سلاح القسمة!)
