## 🎯 القاعدة (سطر واحد!)

# **حقيقي مع حقيقي ، تخيلي مع تخيلي**

## الجمع:
**(س₁ + ص₁ت) + (س₂ + ص₂ت) = (س₁+س₂) + (ص₁+ص₂)ت**

## الطرح:
**(س₁ + ص₁ت) − (س₂ + ص₂ت) = (س₁−س₂) + (ص₁−ص₂)ت**

> 🍎 **تشبيه:** عندك سلتين: سلطة تفاح (حقيقي) وسلطة برتقال (تخيلي). لما تجمع/تطرح، التفاح مع التفاح والبرتقال مع البرتقال — **ما تخلط السلال!**

---

## ✏️ أمثلة محلولة خطوة خطوة

### مثال 1: (3 + 5ت) + (2 − ت) = ؟
- الحقيقي: 3 + 2 = **5**
- التخيلي: 5 + (−1) = **4**
- النتيجة: **5 + 4ت**

### مثال 2: (7 − 4ت) − (2 + 6ت) = ؟
- الحقيقي: 7 − 2 = **5**
- التخيلي: −4 − 6 = **−10**
- النتيجة: **5 − 10ت**

### مثال 3 (بالقوس مهم!): (4 + 3ت) − (6 − 2ت) + (1 + ت) = ؟
- الحقيقي: 4 − 6 + 1 = **−1**
- التخيلي: 3 − (−2) + 1 = 3 + 2 + 1 = **6**
- النتيجة: **−1 + 6ت**

⚠️ **غرّة:** لما تطرح قوس كامل، **انعكس كل الإشارات** داخله! (6 − 2ت) بتصير −6 + 2ت

### مثال 4: أوجد ع إذا: ع + (2 + 3ت) = 8 − ت
- ع = (8 − ت) − (2 + 3ت) = (8−2) + (−1−3)ت = **6 − 4ت**

## 📝 مسائل تدريب

**1)** (5 + 2ت) + (3 + 7ت) = ؟
**2)** (9 − ت) − (4 − 5ت) = ؟
**3)** (−2 + ت) + (−3 − ت) + 5 = ؟
**4)** أوجد ع: ع − (1 + ت) = 4 + 6ت
**5)** (3ت) + (5 − 3ت) = ؟ وشو لاحظت؟

### ✅ الحلول:
1. **8 + 9ت**
2. **5 + 4ت**
3. حقيقي: −2−3+5 = 0 ، تخيلي: 1−1 = 0 ← **0** (العدد صفر!)
4. ع = (4+1) + (6+1)ت = **5 + 7ت**
5. **5 + 0ت = 5** — لاحظ: التخيلي انعكس وشال، والنتيجة عدد حقيقي نقي!

## 🧠 للمحفوظة
- جمع/طرح المركبة = **مكونان مستقلان** (حقيقي↔حقيقي ، تخيلي↔تخيلي)
- طرح قوس = عكس **كل** الإشارات داخله
