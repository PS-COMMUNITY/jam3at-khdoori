**الوحدة الأولى | آخر درس بالوحدة — سؤال كبير شبه مضمون (3 لوحات كاملة بالسبورة!)**

---

## 🎯 الفكرة بجملة واحدة

لما ترفع عدد مركبي (بصورته القطبية) لقوة ن:
# **المقياس يرفع للقوة ن ، والزاوية تضرب بن!**

## القانون:
# **عⁿ = رⁿ (جتا ن·هـ + جا ن·هـ ت)**

> 🚀 **تشبيه:** عندك صاروخ على مسافة ر من المركز وباتجاه زاوية هـ. "القوة ن" = تحطيم صاروخ ن صواريخ: كل صاروخ ابتعد مسافة رⁿ وصار الاتجاه ن·هـ!

## ⚠️ شروط قبل التطبيق (أهم شي!):
1. **حوّل العدد للصورة القطبية أولاً** — ديموافر ما تشتغل على س+صت مباشرة!
2. **زاوية هـ لازم تكون محددة صح حسب الربع** (درس 10)
3. إذا الزاوية طلعت كبيرة (> 2π أو 360°) اختصرها: اطرح 360° (أو 2π) حتى تدخل الدورة

---

## ✏️ أمثلة محلولة (من السبورة نفسها!)

### مثال 1 (من السبورة — النوع المضمون): احسب: (جتا π/12 + جا π/12 ت)⁶
العدد **جاهز قطبي** (ر = 1):
- القوة 6: ر⁶ = 1⁶ = 1 ، الزاوية: 6 × π/12 = **π/2**
- = 1(جتا π/2 + جا π/2 ت) = 1(0 + 1·ت)
# **= ت** ✅ (نفس نتيجة السبورة!)

### مثال 2 (من السبورة): احسب: [ر(جتا π/ن + جا π/ن ت)]ⁿ
- = رⁿ(جتا ن·π/ن + جا ن·π/ن ت) = رⁿ(جتا π + جا π ت)
- وجتا π = −1 ، جا π = 0
# **= −رⁿ** ✅ (ملاحظة السبورة الذهبية!)

### مثال 3: احسب: (1 + ت)⁵
**الخطوة 1 — حوّل للقطبي:** 1+ت: ر = √2 ، هـ = 45° (π/4)
**الخطوة 2 — طبق ديموافر:**
= (√2)⁵ (جتا 5×45° + جا 5×45° ت)
= 4√2 (جتا 225° + جا 225° ت)
**الخطوة 3 — لو بدك كارتيزي:**
جتا 225° = −√2/2 ، جا 225° = −√2/2
= 4√2 × (−√2/2) + 4√2 × (−√2/2) ت = −4 − 4ت
# **= −4 − 4ت** ✅

### مثال 4 (القوة السالبة): احسب: [2(جتا π/6 + جا π/6 ت)]⁻³
- ر⁻³ = 2⁻³ = 1/8 ، الزاوية: −3 × π/6 = −π/2
- = (1/8)(جتا(−90°) + جا(−90°) ت) = (1/8)(0 − ت)
# **= −ت/8** ✅ (قانون السبورة: ز⁻ⁿ)

### مثال 5 (زاوية كبيرة): احسب: (√2(جتا 7π/4 + جا 7π/4 ت))²
- الزاوية: 2 × 7π/4 = 7π/2 → اطرح 2π (= 4π/2): 7π/2 − 2π = 3π/2
- = 2(جتا 3π/2 + جا 3π/2 ت) = 2(0 − ت) = **−2ت**

## 📝 مسائل تدريب

**1)** (جتا π/6 + جا π/6 ت)³ = ؟  **2)** (2(جتا π/4 + جا π/4 ت))⁴ = ؟
**3)** (1 − ت)³ = ؟ (حوّل أولاً!)  **4)** (جتا π/ن + جا π/ن ت)ⁿ إذا ر = 1 = ؟

### ✅ الحلول:
1. 1³(جتا π/2 + جا π/2 ت) = **ت**
2. 2⁴(جتا π + جا π ت) = 16(−1) = **−16**
3. 1−ت: ر = √2 ، هـ = −45° (الرابع!) ← (√2)³(جتا −135° + جا −135° ت) = 2√2(−√2/2 + −√2/2 ت) = **−2 − 2ت**
4. جتا π + جا π ت = **−1**

---

## 🧠 للمحفوظة
- **عⁿ = رⁿ(جتا ن·هـ + جا ن·هـ ت)**
- **قطبي أولاً!** (س+صت ممنوعة)
- جتا π = −1 ، جا π = 0 ، جتا π/2 = 0 ، جا π/2 = 1
- زاوية كبيرة؟ اطرح 2π/360°
