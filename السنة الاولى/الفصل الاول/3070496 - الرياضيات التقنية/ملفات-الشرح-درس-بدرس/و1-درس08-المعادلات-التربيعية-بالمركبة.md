# 🧸 درس 8: حل المعادلات التربيعية بالأعداد المركبة ⭐

**الوحدة الأولى | سؤال رئيسي متوقع — خاصة المميز السالب!**

---

## 🎯 التذكير: القانون العام

معادلة: **أس² + بس + جـ = 0**

# **س = (−ب ± √(ب² − 4أجـ)) ÷ 2أ**

والمقدار **م = ب² − 4أجـ** اسمه **المميّز** — هو اللي بيقرر نوع الحلول:

| المميز م | نوع الحلول |
|----------|------------|
| م > 0 | حلان حقيقيان مختلفان |
| م = 0 | حل حقيقي مكرر |
| **م < 0** | **حلان مركبان مترافقان!** ← درسنا اليوم |

## 🪄 الرقم السحري مع الجذر السالب:
# **√(−ك²) = كت** (نسحب الجذر من الموجب ونضيف ت)
مثال: √(−9) = 3ت ، √(−36) = 6ت ، √(−5) = √5 ت

> 🎈 **تشبيه:** المميز السالب مثل "علم أحمر" يخبرك: "الحلول مش بالعالم الحقيقي — انزل لعالم المركبة!" والحلول راح يكونوا **توأمان متعاكسين** (مترافقان: س ± كت)

---

## ✏️ أمثلة محلولة خطوة خطوة

### مثال 1 (نفس نوع أمثلة السبورة): حل: س² − 4س + 13 = 0
**الخطوة 1:** أ = 1 ، ب = −4 ، جـ = 13
**الخطوة 2:** المميز: م = (−4)² − 4(1)(13) = 16 − 52 = **−36** (سالب ← مركبة!)
**الخطوة 3:** √م = √(−36) = **6ت**
**الخطوة 4:** س = (4 ± 6ت)/2
# **س = 2 ± 3ت** ✅ (حلان: 2+3ت و 2−3ت — مترافقان!)

### مثال 2: حل: س² + 9 = 0
- س² = −9 ← س = ±√(−9) = **±3ت**

### مثال 3: حل: س² + 2س + 5 = 0
- م = 4 − 20 = −16 ← √م = 4ت
- س = (−2 ± 4ت)/2 = **−1 ± 2ت**

### مثال 4: حل: 2س² + 2س + 1 = 0
- م = 4 − 8 = −4 ← √م = 2ت
- س = (−2 ± 2ت)/4 = **(−1 ± ت)/2** = −1/2 ± (1/2)ت

---

## 📝 مسائل تدريب

**1)** حل: س² + 25 = 0
**2)** حل: س² − 6س + 25 = 0
**3)** حل: س² + 4س + 8 = 0
**4)** حل: 3س² − 2س + 2 = 0 (انتبه: القسمة على 2أ = 6)

### ✅ الحلول:
1. س = **±5ت**
2. م = 36−100 = −64 ، √م = 8ت ← س = (6±8ت)/2 = **3 ± 4ت**
3. م = 16−32 = −16 ، √م = 4ت ← س = (−4±4ت)/2 = **−2 ± 2ت**
4. م = 4−24 = −20 ، √م = 2√5 ت ← س = (2 ± 2√5 ت)/6 = **(1 ± √5 ت)/3**

---

## 🧠 للمحفوظة
- المميز **سالب** ← √(الموجب) × **ت**
- الحلان دايماً **مترافقان**: س ± كت
- لا تنسَ **القسمة على 2أ** كاملة!
