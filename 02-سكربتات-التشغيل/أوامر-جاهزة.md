# ⚡ أوامر جاهزة للتنفيذ الفوري

> استبدل `<TUNNEL>` برابط النفق الحي (يُطلب من الطالب عند تغيّره). التوكن الثابت: في الخزنة (`khdoori-vault` → `01-توكنات-الوصول`) — > 🔐 القيم الحقيقية في **الخزنة الخاصة** `khdoori-vault` (يُطلب رابطها من الطالب)

## فحص الحياة (بدون توكن)
```bash
curl -s --max-time 15 https://<TUNNEL>.trycloudflare.com/health
```

## استدعاء أداة عام
```bash
curl -s --max-time 60 -X POST https://<TUNNEL>.trycloudflare.com/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <توكن-المتمم — في الخزنة>" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"<TOOL>","arguments":{...}}}'
```

## عرض مجلد
```bash
... "params":{"name":"file_list","arguments":{"path":"C:\\Users\\__PC_USER__\\Desktop\\جامعة خضوري نحو المستقبل"}} ...
```

## نقل ملف ثنائي (سلسلة مجرَّبة كاملة)
1. من بيئة المساعد: `curl -s -F "file=@local.docx" -A "curl/8.5.0" https://x0.at` → يعيد رابطاً
2. إنشاء المجلدات + التنزيل على الجهاز:
```bash
# placeholder ينشئ مجلدات الأب
... "name":"code_write_file","arguments":{"path":"C:\\...\\final.docx","content":"ph","create_backup":false}" ...
# التنزيل الفعلي
... "name":"file_upload","arguments":{"source_url":"https://x0.at/XXXX.docx","dest_path":"C:\\...\\final.docx","overwrite":true,"timeout_seconds":600}" ...
# التحقق
... "name":"file_list","arguments":{"path":"C:\\...\\parent"} ... → قارن size_bytes
```

## نصائح
- فك JSON الرد: `result.content[0].text` ثم `json.loads` مرة ثانية
- انتظر `networkidle` قبل أي قياس — النفق قد يتأخر
- 429/530 = النفق متقطع — أعد المحاولة أو بدّل النفق
- x0.at: GET فقط (HEAD=404) — التحقق بالتنزيل ومقارنة الحجم/SHA256
