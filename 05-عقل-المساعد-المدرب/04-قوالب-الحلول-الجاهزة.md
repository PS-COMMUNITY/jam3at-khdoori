# 📋 قوالب الحلول الجاهزة — بأفضل وأسهل شكل

> كل قالب: النمط ← الخطوات بالترتيب ← «الأسهل شكلاً» ← مثال مصغر مع تحقق. المساعد يتبعها حرفياً عند أي واجب.

---

## قالب 1: دارة مقاومات (تسلسل/توازي)
**الخطوات:** 1) أعد الرسم وسمِّ العقد 2) اجمع التوازيات أولاً ثم التسلسل 3) I_كلي = V/R_T 4) وزّع (مقسّم جهد/تيار).
**الأسهل شكلاً:** بدّل كل زوج توازي بـ `R₁R₂/(R₁+R₂)` خطوة خطوة على الرسم.
مثال: 12V على (10Ω ت + (20Ω ∥ 20Ω)): R_T = 10+10 = 20Ω ← I = 0.6A
✔ `bun calc.mjs rpar 20 20` ← 10 ثم `bun calc.mjs eval "12/20"` ← 0.6

## قالب 2: قدرة وفاتورة
**الخطوات:** 1) P لكل جهاز 2) الطاقة = P×ساعات ÷1000 3) المجموع × سعر الوحدة.
✔ `bun calc.mjs eval "1500*5/1000 + 200*8/1000"` ← 9.1 kWh

## قالب 3: عمليات الأعداد المركبة
**جمع/طرح:** جزء بجزء. **ضرب:** بالتوزيع + j²=−1. **قسمة:** اضرب بالمترافق.
**الأسهل شكلاً للضرب والقسمة القطبيتين:** حوّل لقطبية ← اجمع/اطرح الزوايا ← أعد للمستطيل إن طُلب.
✔ `bun calc.mjs cdiv "3+4i" "1-2i"` ← -1 + 2i (تحقق ثانٍ: `bun calc.mjs cmul "-1+2i" "1-2i"` ← 3+4i ✓ عوض عكسي)

## قالب 4: منظومة معادلات (رياضيات/دوائر KCL)
**الأسهل شكلاً يدوياً:** الحذف الغاوسي (صفر تحت القطر ثم عوض عكسي).
**تحقق ثانٍ:** كرامر `x = Dx/D` — أو العدة: `bun calc.mjs msolve "[[2,1],[1,3]]" "[5,10]"` ← 1 3
**تحقق ثالث:** عوض الحل في المعادلة الأصلية.

## قالب 5: متسلسلة هندسية (مجموع لامتناهٍ)
**الخطوات:** 1) حدد a₁ وr (اقسم حداً متتاليين) 2) افحص |r|<1 3) `S = a₁/(1−r)`.
✔ مثال: 8+4+2+... : a₁=8, r=1/2 ← S=16. تحقق: `bun calc.mjs sum "8*(0.5)^(n-1)" 1 30` ← 16

## قالب 6: معاملات فورير
**الخطوات:** 1) افحص الزوجية أولاً (فردية←bₙ فقط، زوجية←aₙ فقط) 2) احسب a₀ 3) كرّر التكامل لـ aₙ/bₙ (تكامل بالتجزيء عند الضرب في x) 4) اكتب السلسلة بأول 3 حدود.
✔ تحقق عددي لأي معامل: `bun calc.mjs integrate "t*sin(n*t)" "-3.14159" "3.14159"` ثم ÷π

## قالب 7: تحويل/عكس لابلاس
**للتحويل:** طابق f(t) مع جدول `02-ورقة-قوانين-الرياضيات` — الخطية + الإزاحة.
**للعكس:** فكّ F(s) لكسور جزئية (A/(s−a) + B/(s−a)² + ...) ← طابق الجدول.
**معادلة تفاضلية:** حول ← شروط ابتدائية ← حل F(s) ← عكس.
✔ تحقق عددي لأي نتيجة: `bun calc.mjs laplace "t^2" 3` ← يجب 2/27 = 0.074074

## قالب 8: زينر (اختيار Rs)
**الخطوات:** 1) Rs = (Vin−Vz)/(Iz+IL) 2) افحص قدرة Rs: `P = (Vin−Vz)²/Rs` 3) افحص Iz ضمن الحدود.
✔ `bun calc.mjs eval "(15-9)/(0.02+0.005)"` ← 240Ω

## قالب 9: تقويم (Vdc)
**الخطوات:** 1) حدد النوع (نصف/كامل/جسر) 2) Vdc من الجدول (Vm/π أو 2Vm/π) 3) تردد التموج f أو 2f.
✔ `bun calc.mjs eval "2*12/3.14159"` ← 7.64V

## قالب 10: تحيز BJT
**ثابت:** Ib=(Vcc−0.7)/Rb ← Ic=βIb ← Vce=Vcc−IcRc.
**مقسم جهد:** VB=Vcc·R₂/(R₁+R₂) ← Ve=VB−0.7 ← Ie=Ve/Re ← Ic≈Ie ← Vce=Vcc−Ic(Rc+Re).
**تحقق المعقولية:** لو Vce خرجت سالبة ← الترانزسستور مشبع — أعد بالمنطقة المشبعة.
✔ `bun calc.mjs eval "(12-0.7)/470000*100"` ← 2.4mA

## قالب 11: واجب كتابي (أخلاقيات/عربي/إنجليزي)
1. مقدمة: تعريف بجملة الطالب نفسه (3-4 أسطر)
2. الجوهر: 3 أفكار، كل فكرة = مبدأ ← سبب ← مثال واقعي محلي
3. خاتمة: موقف شخصي بجملة قوية
4. مراجعة إملائية/نحوية نهائية + تسليم قبل الموعد بيوم.

## قالب 12: تقرير ورشة
الهدف ← الأدوات ← الخطوات (مرقمة) ← القياسات الفعلية بالأرقام ← الأخطاء وما تعلمته ← ربط نظري بسطر (قانون من الدوائر).
**قاعدة:** يُكتب في نفس يوم الجلسة — الأرقام لا تعيش في الذاكرة.
