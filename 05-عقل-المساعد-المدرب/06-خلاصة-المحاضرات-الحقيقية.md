# 📼 خلاصة المحاضرات الحقيقية — ما قاله الدكاترة فعلاً (مستخرجة من التفريغات والشرائح)

> هذه ليست ملخصاً عاماً — هذه **الذاكرة الحرفية** للمحاضرات: أمثلة الدكاترة بأرقامها، عباراتهم المتكررة، ونمط أسئلتهم. تُقرأ قبل حل أي واجب/امتحان في هذه المواد.

---

## 1) دوائر — أ. مصطفى (محاضرات 1-7+ من التفريغات + كتاب الطالب/منصور)

### محاضرة 2 (الوحدات والذرة)
- أمثلة محسولة حياً: **25mm + 6000µm = 31mm** (حوّل للصغرى: قسمة على ألف) | **4.5MΩ + 400kΩ = 4.9MΩ** (الطريقتان: للوحدة الأكبر أو الأصغر)
- أسئلة المراجعة بنمطه: «ما الكميات الأساسية في SI ووحداتها ورموزها؟» | «املأ الفراغ: 46µA = ...nA» | «أيها أساسي وأيها مشتق: الفولت؟ الأمبير؟ الكولوم؟» (الفولت والكولوم مشتقان، الأمبير أساسي)
- تصنيف الدوائر: **بسيطة** (حلقة واحدة) و**غير بسيطة** (عدة حلقات).

### محاضرة 3 (المقاومة والمفاعلات)
- المقاومة الأومية: I و V **بنفس الاتجاه** فيها.
- **XL = ωL = 2πfL**: في DC (f=0) ← XL=0 (الملف موصل عادي). في AC: **الجهد يتقدم على التيار 90°**.
- **XC = 1/ωC**: في DC ← ∞ (المكثف **دائرة مفتوحة**). في AC: **التيار يتقدم على الجهد 90°**.
- المقاوم الوحيد الذي لا يصنع فرق طور (I وV متطابقان).
- المواد: موصلات (فضة ← نحاس ← ألمنيوم؛ النحاس الأشهر لرخصه مقارنة بالفضة «ذهب الفقراء») / عوازل / أشباه موصلات. عدد الإلكترونات الحرة يحدد التوصيل.

### محاضرة 4 (الألوان + المقاومة النوعية + الحرارة)
- صيغته للألوان: **R = A·B ×10^C ± D%** — أمثلة محسولة حياً:
  - أحمر/برتقالي/أزرق/ذهبي = 23×10⁶ = **23MΩ ±5%**
  - أصفر/أسود/برتقالي/فضي = 40×10³ = **40kΩ ±10%**
  - أصفر/بنفسجي/أسود/ذهبي = 47×10⁰ = **47Ω ±5%**
- خطي مقابل غير خطي: ميل خط V-I = **مقلوب المقاومة** (الناقلية). مثاله على اللاخطي: **مقاومة فتيل المصباح تزداد لا خطياً**.
- **R = ρL/A**: مثال محسول: سلك مقاومته 10Ω/km وρ=1.7×10⁻⁸ ← القطر ≈ **4.5mm** (A = ρL/R ثم d = √(4A/π))
- الناقلية G = 1/R (موه/سيمينس) | الموصلية γ = 1/ρ (S/m)
- **الحرارة: R₁ = R₀(1 + α·ΔT)** — α للنحاس = **1/234.5** (كما في محاضرته)
- مثال الفتيل (تنغستن): مقاومة التشغيل كبيرة والمقاومة الباردة صغيرة ← **تيار لحظة الإشتعال أعلى بكثير من تيار الاستقرار** — هذا مفهومه المفضل.

### محاضرة 5 (الشغل والطاقة والقدرة)
- «قوانين القدرة **ثلاثة**: P=VI وP=I²R وP=V²/R» — قالها حرفياً مرتين (ليأخذها الطالب حياً).
- تحويلاته الحية: **1 kWh = 3.6×10⁶ J** | **1 Wh = 3.6 kJ = 860 كالوري** | الساعة = 3600 ثانية
- توليد الحرارة: تصادم الإلكترونات الموجهة مع جزيئات المادة (المكافئ الميكانيكي للحرارة = الجول).
- **الدارة المفتوحة: I = 0** | المغلقة: مسار كامل من المصدر وإليه — التيار الاصطلاحي من (+) إلى (−).
- قانون أوم: «V يتناسب طردياً مع I **طالما بقت درجة الحرارة ثابتة**» — ينطبق على **الدارات الخطية فقط**. التحقق العملي: فولتميتر + أميتر + مصدر متغير، ميل الخط = المقاومة.
- أمثلة حية: 6kΩ و30V ← 5mA | 10kΩ و6V ← 0.6mA | موصل 5km مقطعه 20mm² وρ=2.2×10⁻⁸ ← **R = 5.5Ω**

### محاضرة 6 (تسلسل/توازي + القسمان) — أهم محاضرة للنصفي
- تسلسل: تيار واحد، جهد يتوزع **طردياً مع المقاومة** | توازي: جهد واحد، تيار يتوزع **عكسياً مع المقاومة**.
- اشتق أمامه **قانون تقسيم الجهد**: V₁ = E·R₁/(R₁+R₂)
- **قانون تقسيم التيار**: I₁ = I·R₂/(R₁+R₂) — «التيار في فرع = التيار الكلي × مقاومة الفرع **الآخر** على المجموع»
- المقاومات المتساوية بالتوازي: R_eq = R/n (مثاله: ثلاث 30Ω ← 10Ω)
- **مثاله الحي (Rx):** I الكلي 5A، فرع 30Ω يمر فيه 2A ← V=60V ← الفرع الآخر 3A ← **Rx = 20Ω** — ثم تحقق بطريقة ثانية (R_eq=12Ω) — **هذا نمط امتحانه: مسألة بطريقتين**

### أمثلة الكتاب المعتمدة (من PDF المحاضرة 7 — مثال 4/5/6/7)
| المثال | المعطيات | النتائج (مُتحقق منها رقماً ✓) |
|---|---|---|
| **مثال 4** | 150mA على 100Ω ∥ 50Ω | I(100)=**50mA**، I(50)=**100mA** |
| **مثال 5** | 60V على 10Ω + (100∥100) | R_eq=**60Ω**، I₁=**1A**، I₂=I₃=**0.5A**، V₁=**10V**، V₂=V₃=**50V** |
| **مثال 6** | دارة مركبة: 120Ω+ (400∥100) حيث 400=100+300 و100= (60∥30)+80، مصدر 36V | R_eq=**200Ω**، I₁=**180mA**، I₂=**36mA**، I₆=**144mA**، I₄=**48mA**، I₅=**96mA**، V₁=**21.6V**، V₂=**3.6V**، V₃=**10.8V**، V₄=V₅=**2.88V**، V₆=**11.52V** |
| **مثال 7** | 5V و4A | P = VI = **20W** |

> ⚡ **استنتاج استراتيجي:** أسئلة النصفي المرجحة = دارة مركبة كاملة بنمط مثال 6 + سؤال ألوان + سؤال حرارة (R₁=R₀(1+αΔT)) + سؤال قدرة/فاتورة. تدرب على أمثلة الكتاب بأرقامها الأصلية.

## 2) الرياضيات التقنية — أ. نداء (من محاضرتها المحلولة)

### ترميزها الخاص (مهم لورقة الواجب!)
- تكتب العدد المركب **ع** والوحدة التخيلية **ت** (تخيلية): ع = س + ت·ص — والمرافق **ع̄ = س − ت·ص** والمقياس **|ع| = √(س²+ص²)**
- **في ورقتك أمامها استخدم ترميزها** (ت بدل j) أو وضّح — الترميز الغريب يربكها وتُخصم.

### أمثلتها المحلولة الحقيقية
1. **المرافق والمقياس:** ع = 3 + 4ت ← ع̄ = 3−4ت، |ع| = √(9+16) = **5**، |ع̄| = 5 أيضاً، وع×ع̄ = |ع|² = **25**
2. **القسمة (مثال 1):** (2−3ت)/(3+4ت) ← اضرب بالمترافق (3−4ت): البسط = (6−12) + (−8−9)ت = −6 −17ت، المقام = 9+16 = 25 ← **−6/25 − 17/25 ت** ✓ (تحققت بالعدة: −0.24 − 0.68i)
3. **مثال 2:** قسمة بمقياس 5 ← النتيجة بصورة س + ت·ص
4. **المعادلات التربيعية في ك (الأربع طرق):** عامل مشترك / تحليل للعوامل / **القانون العام ζ = (−ب ± √(ب²−4أج))/2أ** / إكمال المربع
5. **أمثلة التربيعية:**
   - س² + 9 = 0 ← س = ±3ت (لا حل حقيقي ← حل مركب)
   - **2س² + 4س + 3 = 0**: المميز = 16−24 = **−8** ← س = (−4±√8·ت)/4 = **−1 ± (√2/2)ت** ✓
   - **ع(1+ع) = ع²** ← ع² + ع + 1 = 0: المميز = −3 ← **ع = (−1±√3·ت)/2** (جذور الوحدة التكعيبية!)
6. منهجية خطواتها المكتوبة: (1) نجد مرافق المقام (2) نجد مقياس المقام (3) نطبق القانون — **ثلاث خطوات مكتوبة** — اكتبها مثله.
