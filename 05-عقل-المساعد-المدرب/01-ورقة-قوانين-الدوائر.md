# 🧮 ورقة القوانين الكاملة — الدوائر الكهربائية

> مبنية على محاضرات 1-6 الفعلية (شرائح أ. مصطفى) + ما سيأتي في الوحدات القادمة. المصطلحات بنفس لغة الشرائح.

## 1) الوحدات والبادئات (مح 1-2)
| البادئة | رمز | قيمة | | البادئة | رمز | قيمة |
|---|---|---|---|---|---|---|
| بيكو | p | 10⁻¹² | | ميلي | m | 10⁻³ |
| نانو | n | 10⁻⁹ | | كيلو | k | 10³ |
| ميكرو | µ | 10⁻⁶ | | ميجا | M | 10⁶ |

نظام SI: الأمبير (I)، الفولت (V)، الأوم (Ω)، الواط (P)، الكولوم (Q)، الهنري (L)، الفاراد (F)، الثانية (s)، الهيرتز (Hz).

## 2) الشحنة والتيار (مح 3)
- `I = Q/t` — الأمبير = كولوم/ثانية
- شحنة الإلكترون: `e = 1.602×10⁻¹⁹ C` ← عدد الإلكترونات: `n = Q/e`
- الذرة والنحاس: مستوى التكافؤ `2n²` — النحاس إلكترون تكافؤ واحد حر ← موصل ممتاز.

## 3) الجهد والقوة الدافعة (مح 3)
- `V = W/Q` — الفولت = جول/كولوم
- **emf** (القوة الدافعة الكهربائية) = طاقة معطاة لكل وحدة شحنة داخل المصدر
- فرق الجهد على الطرفين: `V = emf − I·r` حيث r المقاومة الداخلية للمصدر.

## 4) المقاومة (مح 3)
- قانون أوم: **`V = I·R`** ← `I = V/R`، `R = V/I`
- اعتماداً على الأبعاد: `R = ρ·L/A` (ρ المقاومة النوعية، L الطول، A المساحة)
- المواد: موصلات (نحاس، ألمنيوم) / عوازل (بلاستيك، مطاط) / أشباه موصلات (سيليكون، جيرمانيوم).

## 5) المفاعلات (مح 3) — التيار المتردد
- الحثية: **`XL = 2πfL`** (تزيد مع التردد)
- السعوية: **`XC = 1/(2πfC)`** (تنقص مع التردد)

## 6) قراءة المقاومة بالألوان (مح 3-4)
| اللون | رقم | | اللون | مضاعف | سماحية |
|---|---|---|---|---|---|
| أسود 0 | بني 1 | أحمر 2 | ذهبي | ×0.1 | ±5% |
| برتقالي 3 | أصفر 4 | أخضر 5 | فضي | ×0.01 | ±10% |
| أزرق 6 | بنفسجي 7 | رمادي 8 | بلا لون | — | ±20% |
| أبيض 9 | | | | | |

**القراءة:** النطاقان الأولان رقمان، الثالث مضاعف (أصفار)، الرابع سماحية — والسماحية دائماً أقصى اليمين.
مثال الدكتور: أحمر/أسود/أزرق/فضي = 2،0،×10⁶ ← 20MΩ ±10%.

## 7) الشغل والطاقة والقدرة (مح 5)
- القدرة: **`P = V·I = I²R = V²/R`** (واط W)
- الشغل/الطاقة: `W = P·t` (جول) — والوحدة التجارية: **كيلوواط-ساعة kWh**
- `1 kWh = 3.6×10⁶ J` — الفاتورة = (ق watt × ساعات ÷ 1000) × سعر الوحدة.

## 8) دوائر DC البسيطة (مح 6 وما بعدها)
- تسلسل: `R_T = R₁ + R₂ + ...` — التيار واحد، الجهد يتوزع (مقسّم الجهد: `V₁ = V·R₁/R_T`)
- توازي: `1/R_T = 1/R₁ + 1/R₂ + ...` (اثنان: `R₁R₂/(R₁+R₂)`) — الجهد واحد، التيار يتوزع (مقسّم التيار)
- مفهوم الحمل: كل مستهلك = مقاومة تسحب تياراً من المصدر.

## 9) قوانين كيرشوف (القادم)
- KCL (عقدة): مجموع التيارات الداخل = الخارج
- KVL (حلقة): مجموع الارتفاعات = مجموع الهبوطات.

## 10) التيار المتردد — الممانعة (القادم — يرتبط بالأعداد المركبة)
- `Z = R + j(XL − XC)` — المقدار `|Z| = √(R² + (XL−XC)²)`
- `I = V/|Z|` — زاوية الطور `φ = tan⁻¹((XL−XC)/R)`
- معامل القدرة: `cosφ = R/|Z|` — القدرة الحقيقية `P = V·I·cosφ`
- الرنين: `f₀ = 1/(2π√(LC))`.
