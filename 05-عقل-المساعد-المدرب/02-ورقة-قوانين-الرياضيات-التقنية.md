# 📊 ورقة القوانين الكاملة — الرياضيات التقنية (الوحدات الست)

> بنفس ترتيب خطة أ. نداء. كل قسم يُختم بأمر تحقق بالعدة.

## الوحدة 1: الأعداد المركبة
- التعريف: `z = a + jb`، حيث `j² = −1` (a حقيقي، b تخيلي)
- التساوي: حقيقي = حقيقي، تخيلي = تخيلي (لا مقارنة ترتيبية بين مركبين)
- الجمع/الطرح: جزء بجزء
- الضرب: بالتوزيع مع اختصار كل `j² = −1`
- **القسمة (الأسهل):** اضرب بسطاً ومقاماً في **مترافق المقام** `(c−jd)`
- المقدار: `|z| = √(a²+b²)` — الزاوية: `θ = tan⁻¹(b/a)` (انتبه للربع)
- الصيغة القطبية: `z = r∠θ = r(cosθ + j·sinθ) = r·e^(jθ)`
- الضرب قطبياً (أسهل شكل): `r₁∠θ₁ × r₂∠θ₂ = r₁r₂∠(θ₁+θ₂)` — والقسمة: تقسيم الأقدار وطرح الزوايا
- دي موافر: `zⁿ = rⁿ∠nθ` — الجذور n: `r^(1/n)∠((θ+360k)/n)`

✔ التحقق: `bun calc.mjs cdiv "3+4i" "1-2i"` ← -1 + 2i | `bun calc.mjs cpolar "3+4i"` ← 5∠53.13°

## الوحدة 2: المتتاليات والمتسلسلات
- حسابية: `aₙ = a₁ + (n−1)d` — مجموع n: `Sₙ = n/2·(2a₁ + (n−1)d)`
- هندسية: `aₙ = a₁·r^(n−1)` — `Sₙ = a₁(1−rⁿ)/(1−r)` (r≠1)
- اللامتناهية: `S∞ = a₁/(1−r)` **فقط إذا |r| < 1** (وإلا متباعدة)
- تقارب سلسلة 1/nᵖ: تتقارب إذا p > 1.

✔ التحقق: مجموع أول 20 حد لـ 1/2ⁿ: `bun calc.mjs sum "1/2^n" 1 20`

## الوحدة 3: متسلسلة فورير (على (−π, π) أو (0, 2π))
```
f(x) = a₀/2 + Σ [aₙ·cos(nx) + bₙ·sin(nx)]
a₀ = (1/π)∫f(x)dx      aₙ = (1/π)∫f(x)cos(nx)dx      bₙ = (1/π)∫f(x)sin(nx)dx
```
- **الأسهل شكلاً:** f زوجية ← كل `bₙ = 0` | f فردية ← كل `aₙ = 0` (لاحظ الزوجية قبل التكامل!)
- دورة 2L: استبدل nx بـ nπx/L.

✔ التحقق العددي لمعامل: `bun calc.mjs integrate "t*cos(2*t)" "-3.14159" "3.14159"` ثم ÷π

## الوحدة 4: تحويل لابلاس
الجدول الأساسي (s > 0):
| f(t) | F(s) |
|---|---|
| 1 | 1/s |
| tⁿ | n!/s^(n+1) |
| e^(at) | 1/(s−a) |
| sin(ωt) | ω/(s²+ω²) |
| cos(ωt) | s/(s²+ω²) |
| t·e^(at) | 1/(s−a)² |
| e^(at)sin(ωt) | ω/((s−a)²+ω²) |
| sinh/cosh | ω/(s²−ω²)، s/(s²−ω²) |

- الخطية + الإزاحة: `L{e^(at)f(t)} = F(s−a)`
- المشتقات: `L{f'} = sF(s) − f(0)` — `L{f''} = s²F(s) − s·f(0) − f'(0)`
- حل معادلة تفاضلية: حول كل حد ← عوض الشروط الابتدائية ← حل F(s) جبرياً ← عكس التحويل من الجدول (تفكيك كسور جزئية).

✔ تحقق عددي (لا يغني عن الجدول لكنه يؤكد): `bun calc.mjs laplace "sin(t)" 2` ← 0.2 = 1/(4+1) ✓

## الوحدة 5: المتجهات
- المقدار: `|v| = √(x²+y²+z²)` — متجه الوحدة: `v/|v|`
- الضرب القياسي: `u·v = u₁v₁ + u₂v₂ + u₃v₃ = |u||v|cosθ` — التعامد: u·v = 0
- الضرب الاتجاهي: `|u×v| = |u||v|sinθ` (مساحة متوازي الأضلاع) — عمودي على الاثنين، بقاعدة اليد اليمنى:
  `u×v = |i j k; u₁ u₂ u₃; v₁ v₂ v₃|`
- الإسقاط: `proj_v(u) = (u·v/|v|²)·v`.

✔ التحقق: `bun calc.mjs eval "1*2+2*0+3*(-1)"` ← u·v للنقط (1,2,3)·(2,0,−1)

## الوحدة 6: المصفوفات
- الضرب: صف×عمود — `(m×n)(n×p) = m×p`
- المحدد 2×2: `ad − bc` | 3×3: ساروس أو التوسيع بالصف الأول
- المعكوس 2×2: `1/(ad−bc) × [d −b; −c a]` | الأكبر: Gauss–Jordan
- حل منظومة: Gauss (الأسهل يدوياً) أو كرامر: `x = Dx/D` (التحقق: D ≠ 0)
- `A⁻¹A = I` — التحقق النهائي لأي معكوس: اضرب وأكد الوحدة.

✔ التحقق: `bun calc.mjs msolve "[[2,1],[1,3]]" "[5,10]"` ← 1 3 | `bun calc.mjs minv "[[4,7],[2,6]]"`
