# 🎭 أسلوب كل دكتور — صياغة الحلول حسب المُصحِّح

> القاعدة: الحل الصحيح بأسلوب غير محبب قد يخسر درجات. هنا «كيف تُكتب الورقة» لكل دكتور — من الرصد الفعلي.

| الدكتور | شكل الحل المطلوب | ممنوعات | مفاتيح الذهب |
|---|---|---|---|
| **مصطفى (دوائر)** | حل بيدك منظّم: قانون ← عوض ← نتيجة مؤطرة. صورة واضحة مضاءة عند التسليم اليدوي | فوضى الأقواس، حل ذهني بلا خطوات | اطلب التمديد **بلطف ومبكراً** (تم فعلياً) — قارن دائماً بـ«نسخة الدكتور» على المودل |
| **نداء (رياضيات)** | خطوات كاملة مرقمة، كل جواب بترتيب هندسي، الإشارات مفحوصة | الاختصار «البديهي»، الورقة المائلة المظلمة | راقب الإشعارات (قناتها) — الواجبات صورة تُحل وتُرفع — الدقة = الدرجة |
| **لينا (إلكترونيات)** | حل بترقيم أرشيفها + رسم المنحنى I-V عند أي مكوّن | إجابات بلا رسم منحنى للديود/الترانزستور | صفحات «بداية ونهاية الامتحان» تحدد المدى — الأسئلة الإثرائية المحلولة في الأرشيف للتمرين لا للنسخ |
| **همام (مشغل هندسي)** | تقرير يوم الجلسة: هدف/أدوات/خطوات/قياسات/أخطاء | تقرير من الذاكرة بعد أسبوع | حضور قبل 10 دقائق، اسأل أثناء العمل مباشرة (ودود ويجيب) |
| **رغد (أخلاقيات)** | قالب: مقدمة ← 3 مبادئ بمثال واقعي ← خاتمة برأيك | نسخ من النت، حشو | لا تمديدات معروفة — سلّم قبل الموعد بيوم |
| **علي (تمديدات)** | توثيق فوري لكل شرح حي + تقرير بقياسات حقيقية | الاعتماد على المودل (فارغ فعلياً) | مصدرك: الورشة + ملفات المساعد — اربط كل عملية بقانون دوائر |
| **فيصل (عربي)** | مفردات ← معنى عام ← استنتاج. حل بنفسك ثم قارن ب«نسخة الدكتور» | نسخ حرفي، إهمال الإملاء | **راقب رسائل المودل يومياً** — مواعيده تصل هناك (امتحان 12/11 مثلاً) |
| **ناديه (إنجليزي)** | Writing: جمل قصيرة صحيحة بقالب ثابت، مفردات من Glossary الوحدة | التأخير (الثمن موثق: فيديو تكميلي!) | تنبيه هاتف قبل كل Quiz بساعة — احضر Mock Quiz دائماً |

## قواعد عابرة للمواد
1. الاسم والرقم الجامعي أعلى كل ورقة: محمد عادل محمد العقيلي — 202610414.
2. التسليم قبل الموعد بيوم = درع ضد أي عطل.
3. بعد كل تصحيح: الملاحظة تُنقل هنا (جدول يُحدَّث) ودفتر أخطاء الطالب.
4. أي نمط جديد يظهر في تصحيح ← يُضاف فوراً لهذا الملف والقوالب.

## سجل الملاحظات المحدثة (يُحدَّث بعد كل تقييم)
- دوائر، واجب 1 (5/10): خصومات خطوات ونظافة — الحل اليدوي يحتاج ترتيباً أعلى. ← عولج في قالب 1 وصياغة المرحلة 4.
- رياضيات، واجب 1 (8/10): التخفيض -2 لدقة — قوالب 3/4 تفرض فحص إشارات مزدوجاً.
- إنجليزي Writing (9/10): القالب الثابت يعمل — ثبّته لكل الواجبات القادمة.
