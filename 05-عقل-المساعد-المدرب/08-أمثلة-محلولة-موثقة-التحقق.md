# 📝 أمثلة محلولة موثقة — كل رقم تحقق بالعدة قبل النشر

> هذه «بطاقة الحلول المرجعية»: عند أي سؤال مشابه، يُقلد هذا الأسلوب حرفياً. كل مثال: الحل بخطوات الدكتور + أمر التحقق + نتيجته + تحقق ثانٍ.

---

## مثال 1 — تقسيم التيار (مثال 4 من كتاب الدوائر)
**المعطى:** تيار 150mA يدخل فرعين متوازيين: 100Ω و50Ω. المطلوب: I₁ وI₂.
**الحل (أسلوب الدكتور):**
```
I₁ = I × R₂/(R₁+R₂) = 150 × 50/(100+50) = 150 × 50/150 = 50 mA
I₂ = I × R₁/(R₁+R₂) = 150 × 100/150 = 100 mA
```
**التحقق 1 (العدة):** `bun calc.mjs eval "150*50/(50+100)"` ← 50 ✓
**التحقق 2 (كيرشوف):** 50 + 100 = 150mA = التيار الداخل ✓

## مثال 2 — دارة متسلسلة-توازية (مثال 5 من الكتاب)
**المعطى:** 60V على R₁=10Ω على التوالي مع R₂=100Ω ∥ R₃=100Ω.
**الحل:**
```
R_eq2 = 100×100/(100+100) = 50Ω
R_eq  = 10 + 50 = 60Ω
I₁    = 60/60 = 1A        (تيار التوالي الواحد)
I₂ = I₃ = 1 × 100/200 = 0.5A   (تقسيم تيار)
V₁ = 1×10 = 10V    V₂ = V₃ = 0.5×100 = 50V
```
**التحقق:** `rpar 100 100`←50، `rser 10 50`←60، `eval "60/60"`←1، `eval "1*100/200"`←0.5 ✓
**التحقق الثاني:** 10 + 50 = 60V = المصدر ✓

## مثال 3 — الدارة المركبة الكاملة (مثال 6 من الكتاب) ⭐ نمط النصفي الأرجح
**المعطى:** مصدر 36V؛ R₁=120Ω ثم التوازي بين: [فرع أ: R₂=100+R₃=300] و[فرع ب: (R₄=60∥R₅=30)+R₆=80].
**الحل بالترتيب:**
```
فرع أ: 100+300 = 400Ω
فرع ب: 60∥30 = 20Ω ← +80 = 100Ω
التوازي: 400×100/500 = 80Ω
R_eq = 120+80 = 200Ω
I₁ = 36/200 = 0.18A = 180mA
تقسيم تيار: I₂ = 0.18×100/500 = 36mA ، I₆ = 0.18−0.036 = 144mA
داخل فرع ب: I₄ = 0.144×30/90 = 48mA ، I₅ = 144−48 = 96mA
الجهود: V₁=21.6V ، V₂=3.6V ، V₃=10.8V ، V₄=V₅=2.88V ، V₆=11.52V
```
**التحقق بالعدة (كل خطوة):** rser 100 300←400 | rpar 60 30←20 | rser 20 80←100 | rpar 400 100←80 | rser 80 120←200 | eval 36/200←0.18 | I₂←0.036 | I₆←0.144 | I₄←0.048 ✓
**التحقق 2 (كيرشوف للجهود):** V₁ + V_توازي = 21.6 + 14.4 = **36V** = المصدر ✓ | I₂+I₆ = 180mA ✓ | I₄+I₅ = 144mA ✓

## مثال 4 — مقاومة موصل (من محاضرة 5 حرفياً)
**المعطى:** موصل طوله 5km، مساحة مقطعه 20mm²، ρ = 2.2×10⁻⁸ Ω·m.
**الحل:**
```
L = 5000m ، A = 20×10⁻⁶ m²   (تحويل mm² ← m²: ×10⁻⁶)
R = ρL/A = 2.2×10⁻⁸ × 5000 / (20×10⁻⁶) = 5.5Ω
```
**التحقق:** `eval "2.2e-8*5000/(20e-6)"` ← **5.5** ✓
**فحص معقولية:** مقاومة كيلومترات من موصل بضع أوم — منطقي ✓

## مثال 5 — الحرارة وتيار الإشتعال (مفهوم محاضرة 4 بصياغة نظيفة)
**المعطى:** مصباح تنغستن 200W على 220V؛ α = 5×10⁻³/°C؛ حرارة الغرفة 20°C وحرارة التشغيل 2000°C.
**الحل:**
```
R_hot  = V²/P = 220²/200 = 242Ω
R_cold = R_hot/(1+αΔT) = 242/(1+0.005×1980) = 242/10.9 ≈ 22.2Ω
I_إشتعال = 220/22.2 ≈ 9.9A     مقابل I_استقرار = 200/220 ≈ 0.91A
```
**التحقق:** eval "220*220/200"←242 | eval "242/(1+0.005*1980)"←22.2 | eval "220/22.2"←9.91 ✓
**الاستنتاج الذي يريد الدكتور:** تيار لحظة الإشتعال ≈ **11 ضعف** تيار الاستقرار — لهذا تحترق المصابيح لحظة التشغيل.

## مثال 6 — الفاتورة (نمط محاضرة 5)
**المعطى:** 10 مصابيح × 100W + سخان 1200W على 220V، تشغيل 10 ساعات يومياً.
**الحل:**
```
P_كلي = 10×100 + 1200 = 2200W
I = P/V = 2200/220 = 10A
E_يومي = 2200×10/1000 = 22kWh  ← شهرياً ×30 = 660kWh
التكلفة = 660 × سعر الوحدة (مثلاً 0.5 شيكل) = 330 شيكل
```
**التحقق:** eval "10*100*10/1000+1200*10/1000"←22 | eval "2200/220"←10 ✓

## مثال 7 — قسمة مركبة بأسلوب نداء (مثالها 1)
**المطلوب:** (2−3ت)/(3+4ت) على الصورة س+ت·ص.
**الحل بخطواتها الثلاث:**
```
1) مرافق المقام: 3−4ت
2) مقياس المقام: √(9+16) = 5 (ومربعه 25)
3) التطبيق: (2−3ت)(3−4ت)/25 = [(6−12) + (−8−9)ت]/25
            = −6/25 − 17/25 ت  = −0.24 − 0.68ت
```
**التحقق:** `bun calc.mjs cdiv "2-3i" "3+4i"` ← **-0.24 - 0.68i** ✓ (مطابق تماماً لحلها)
**تحقق ثانٍ (عوض عكسي):** اضرب الناتج في المقام: `cmul "-0.24-0.68i" "3+4i"` ← 2−3i ✓

## مثال 8 — المقياس والقطبية
ع = 3 + 4ت: `cpolar "3+4i"` ← **5 ∠ 53.13°** — وإن عكسنا: `crect "5" "53.13"` ← 3+4i ✓ (تحقق تبادلي)

## مثال 9 — تربيعية بمميز سالب (مثالها 2)
**المعادلة:** 2س² + 4س + 3 = 0
**الحل:** المميز = ب²−4أج = 16−24 = **−8** ← سالب ← حلان مركبان
```
س = (−4 ± √8·ت)/(2×2) = −1 ± (√2/2)ت ≈ −1 ± 0.707ت
```
**التحقق:** eval "16-24"←−8 | eval "sqrt(2)/2"←0.707107 ✓

## مثال 10 — تربيعية بتحليل (مثالها 3)
ع(1+ع) = ع² ← ع + ع² = ع² ... النموذج المطلوب منه فعلياً: **ع² + ع + 1 = 0**: المميز = 1−4 = −3 ← ع = (−1 ± √3·ت)/2 ≈ −0.5 ± 0.866ت
**التحقق:** eval "sqrt(3)/2"←0.866025 ✓ | (تعرف: هذان جذرا الوحدة التكعيبية — مجموعهما −1 وحاصل ضربهما 1)

## مثال 11 — متسلسلة هندسية لامتناهية
8 + 4 + 2 + ... : a₁=8، r=1/2 (|r|<1 ✓) ← S = 8/(1−0.5) = **16**
**التحقق:** `sum "8*(0.5)^(n-1)" 1 30` ← **16** ✓ (تقارب فعلي للمجموع)

## مثال 12 — زينر (إلكترونيات)
**المعطى:** مصدر 15V، زينر 9V، تيار حمل 20mA، تيار زينر 5mA.
**الحل:** Rs = (Vin−Vz)/(Iz+IL) = (15−9)/(0.025) = **240Ω**
**التحقق:** eval "(15-9)/(0.02+0.005)"←240 ✓ | فحص قدرة Rs: (15−9)²/240 = 0.15W ← استخدم مقاومة ¼W ✓

## مثال 13 — تقويم موجة كاملة
**المعطى:** قمة الثانوية Vm = 12V، جسر 4 ديودات.
**الحل:** Vdc = 2Vm/π = 2×12/3.14159 ≈ **7.64V**، تردد التموج = 2f
**التحقق:** eval "2*12/3.14159"←7.639 ✓ | فحص معقولية: بين نصف الموجة (3.82) والقمة (12) ✓
