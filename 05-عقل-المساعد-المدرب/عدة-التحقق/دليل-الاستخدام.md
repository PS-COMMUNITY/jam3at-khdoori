# 🧰 عدة التحقق الحسابي — دليل الاستخدام

> أداة سطر أوامر واحدة `calc.mjs` — صفر تبعيات (bun أو node). **الغرض:** التحقق المزدوج في المرحلة 3 من بروتوكول الحل — لا رقم يُسلَّم قبل أن يمر من هنا.

## التشغيل
```bash
cd "05-عقل-المساعد-المدرب/عدة-التحقق"
bun calc.mjs <أمر> <معاملات...>     # أو: node calc.mjs ...
```

## الأوامر (مع أمثلة مجرَّبة)

### حساب عام
```bash
bun calc.mjs eval "sqrt(16)+2^3"          # 12
bun calc.mjs eval "12/100"                # 0.12  (تيار دارة 12V/100Ω)
bun calc.mjs eval "x^2+3" x 5             # 28   (تعريف متغير)
bun calc.mjs eval "1500*5/1000"           # 7.5  (kWh مكيف 1500W × 5 ساعات)
```
الدوال: `sqrt sin cos tan asin acos atan sind cosd tand exp ln log abs floor ceil atan2 pow` — الثوابت: `pi e`
⚠ الضرب الضمني غير مدعوم — اكتب `2*t` لا `2t`. زوايا sin/cos بالراديان، وsind/cosd بالدرجات.

### الأعداد المركبة (رياضيات/دوائر AC)
```bash
bun calc.mjs cadd "3+4i" "1-2i"    # 4 + 2i
bun calc.mjs csub "3+4i" "1-2i"    # 2 + 6i
bun calc.mjs cmul "3+4i" "1-2i"    # 11 - 2i
bun calc.mjs cdiv "3+4i" "1-2i"    # -1 + 2i
bun calc.mjs cpolar "3+4i"         # 5 ∠ 53.130102°
bun calc.mjs crect "5" "53.13"     # 3.000007 + 3.999995i
```
يُقبل i أو j، وأشكال: "3", "3i", "-3+4j", "5i".

### المصفوفات والمنظومات
```bash
bun calc.mjs msolve "[[2,1],[1,3]]" "[5,10]"   # 1  3
bun calc.mjs mdet  "[[1,2],[3,4]]"             # -2
bun calc.mjs minv  "[[4,7],[2,6]]"             # [0.6, -0.7] / [-0.2, 0.4]
bun calc.mjs mmul  "[[1,2],[3,4]]" "[[5,6],[7,8]]"   # [19, 22] / [43, 50]
```

### تحليل عددي
```bash
bun calc.mjs sum "1/2^n" 1 20        # 0.999999   (مجموع متسلسلة)
bun calc.mjs integrate "t^2" 0 2     # 2.666667   (= 8/3)
bun calc.mjs deriv "x^3" 2           # 12         (مشتقة عند نقطة)
bun calc.mjs laplace "sin(t)" 2      # 0.2        (تحقق عددي: 1/(s²+1)=1/5)
bun calc.mjs laplace "t^2" 3         # 0.074074   (= 2/27)
```
⚠ laplace تحقق عددي فقط (لا يغني عن الجدول التحليلي — يثبت صحته).

### مقاومات (دوائر)
```bash
bun calc.mjs rser 10 20 30     # 60        (تسلسل)
bun calc.mjs rpar 10 20        # 6.666667  (توازي)
bun calc.mjs rpar 20 20 10     # 5         (ثلاث توازي)
```

## خريطة الاستخدام في البروتوكول
| المرحلة | الاستخدام |
|---|---|
| حل مسألة مركبة | cmul/cdiv للنتيجة النهائية + **تحقق عوض عكسي** (اضرب الناتج بالمقام — يجب يعطي البسط) |
| منظومة معادلات | msolve ثم عوض الحل يدوياً في المعادلة الأصلية |
| تكامل فورير | integrate للمعامل ثم قسّم على π |
| لابلاس | الجدول أولاً، laplace للتحقق |
| دوائر | rser/rpar للتبسيط ثم eval لكل خطوة |
| أي نتيجة نهائية | قارن بالمعقولية (وحدة + حجم منطقي) |
