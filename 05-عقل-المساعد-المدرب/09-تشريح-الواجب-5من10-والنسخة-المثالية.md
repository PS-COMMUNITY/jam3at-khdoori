## 2) الخصومات الثمانية الموثقة (بند بند من ورقتي الفعلية)

1. **منهج غير معلن:** استخدمت ثيفنن (مادة متقدمة لاحقاً بالمنهج) بدون كتابة اسم القانون ولا خطواته الثابتة — الدكتور يريد: **قانون ← عوض ← نتيجة مؤطرة**. حضّر خلفية نظرية مشتتة بدل ثلاثة أسطر مباشرة.
2. **وحدات ناقصة على الخطوات الوسيطة:** 0.5 بلا A، 25 بلا V، 33.33 بلا V، 7.5 بلا Ω — الوحدة جزء من الجواب عنده.
3. **رمز غير معياري:** كتبت **K** للمقاومة الداخلية بدل **r** (رمز المحاضرة 3 ورمز صيغة الواجب نفسها «المقاومة الداخلية للبطارية»).
4. **ترميز ملتبس:** `20-20÷10` — تُقرأ 20−(20÷10)=18 خطأً! المطلوب `(20−20)÷10=0`.
5. **شطب وطمس وكلمات مشوهة:** «6» مشطوبة فوق 0.667، عبارة «اصطادي الذي فوق جهله» مهملة، تعجب «!» داخل حل رسمي، كلمات مثل «القلاء» غير مقروءة.
6. **التصوير:** الصفحة الثالثة مصوّرة **جانبية 90°** والخلفية لحاف — والملاحظة 1 بالواجب تنص: صورة واضحة مضاءة. + ورقة مفكرة ممزقة الحافة بدل A4 نظيف.
7. **هيدر الورقة خاطئ:** مكتوب «مواد كهربائية تمويد/تمديد 1» بدل **«الدوائر الكهربائية — الواجب الأول»** (نسخت هيدر واجب آخر بنفس المحبرة).
8. **إجابات نهائية مبعثرة:** I₁ وI₂ وI₃ موزعة على صفحتين بلا جدول إجابات جامع مؤطر آخر الحل — المصحح يجمعها بنفسه = إزعاج = خصم.

> ⚠️ **قاعدة مستخرجة:** في مساق مصطفى: جواب صحيح بورقة فوضوية = 5/10. نفس الأرقام بورقة منظمة = 10/10. **الصياغة نصف الدرجة فعلياً.**

## 3) النسخة المثالية 10/10 (انقلها بخط يدك كما هي لو أعيد الواجب)

### الهيدر (إلزامي)
```
الاسم: محمد عادل محمد العقيلي          الرقم: 202610414
المساق: الدوائر الكهربائية 3081071 — الواجب الأول — الشعبة 1
```

### س1 — دارة البطاريتين
```
الترتيب: أرقّم العقد: X = العقدة المشتركة (h,k,c) | Y = العقدة المشتركة (d,e,f)

الخطوة 1 (قانون المقاومة المكافئة للتسلسل):
  R_الفرع الأيسر = 10 + 20 = 30 Ω

الخطوة 2 (قانون جهد العقدة — KCL عند X):
  المجموع (E/R) = 40/30 + 20/10 = 1.333 + 2 = 3.333 A
  المجموع (1/R) = 1/30 + 1/30 + 1/10 = 0.1667 S
  V_X = 3.333 ÷ 0.1667 = 20 V   [نؤطر]

الخطوة 3 (قانون أوم لكل فرع):
  I₁ (تيار بطارية 40V) = (40 − 20)/30 = 0.667 A   [نؤطر]
  I₂ (تيار بطارية 20V) = (20 − 20)/10 = 0 A        [نؤطر — البطارية متوازنة لا تمرر تياراً]
  I₃ (تيار مقاومة 30Ω) = 20/30 = 0.667 A            [نؤطر]

الخطوة 4 (فرق الجهد V_ag — مشيولجة من a إلى g):
  V_a = 40 V
  V_b = 40 − (0.667)(10) = 33.33 V
  V_X = 33.33 − (0.667)(20) = 20 V
  V_g = 20 − 20 = 0 V
  V_ag = V_a − V_g = 40 − 0 = 40 V   [نؤطر]

الخطوة 5 (التحقق المزدوج):
  ثيفنن: I₀=(40−20)/40=0.5A ← V_th=25V ← R_th=(30×10)/40=7.5Ω ← I₃=25/37.5=0.667A ✓
  توازن القدرة: 40×0.667 = 26.67W = 0.667²×(60) ✓

جدول الإجابات النهائي:
  ┌────────────────────────────────┐
  │ I(بطارية 40V) = 0.667 A        │
  │ I(بطارية 20V) = 0 A            │
  │ I(مقاومة 30Ω) = 0.667 A        │
  │ V_ag = 40 V                    │
  └────────────────────────────────┘
```

### س2 — القوة الدافعة والمقاومات
```
الخطوة 1 (المفتوح): لا تيار ← قراءة الفولتميتر = القوة الدافعة
  E = 3.08 V   [نؤطر]

الخطوة 2 (المغلق) قانون القوة الدافعة: V = E − I·r
  r = (E − V)/I = (3.08 − 2.97)/1.6 = 0.11/1.6 = 0.069 Ω   [نؤطر]

الخطوة 3 قانون أوم للحمل: V = I·R
  R = V/I = 2.97/1.6 = 1.86 Ω   [نؤطر]

التحقق: E = I(R + r) = 1.6 × (1.86 + 0.069) = 3.08 V ✓

جدول الإجابات النهائي:
  ┌──────────────────────────────┐
  │ E = 3.08 V                   │
  │ r = 0.069 Ω                  │
  │ R = 1.86 Ω                   │
  └──────────────────────────────┘
```

### قواعد التصوير والتسليم (من خصومات فعلية)
- ورق A4 أبيض نظيف (لا مفكرة حلزونية) — خط واضح بلا شطب.
- كل صفحة عمودية بالصورة، خلفية مستوية مضاءة، المحتوى يملأ الإطار.
- الهيدر أعلى كل صفحة: الاسم + الرقم + **اسم المساق الصحيح** + رقم الواجب.
- آخر شيء بكل سؤال: **جدول إجابات نهائي مؤطر** — المصحح يقيّم من الجدول أولاً.
