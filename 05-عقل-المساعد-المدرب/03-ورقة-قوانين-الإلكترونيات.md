# 🔬 ورقة القوانين الكاملة — الإلكترونيات

> مبنية على سلسلة أ. لينا (أشباه الموصلات ← ديود ← زينر ← BJT/JFET ← Op-Amp). المصطلحات القياسية بنفس ترتيب أرشيفها.

## 1) أشباه الموصلات
- السيليكون Si (الأشهر، 0.7V) والجيرمانيوم Ge (0.3V)
- المنشطات: **n** (خماسي — فوسفور): إلكترونات حرة = حاملات أغلبية | **p** (ثلاثي — بورون): فجوات = حاملات أغلبية
- وصلة pn: طبقة استنفاد + حاجز جهد — الأمامي (p للـ+) يمر، العكسي يسد.

## 2) الديود
- معادلة الديود: `I = I₀(e^(V/nVT) − 1)` — `VT ≈ 26mV` في حرارة الغرفة (نموذجي n=1)
- النموذج العملي: أمامي = مفتاح + هبوط ثابت 0.7V (Si) | عكسي = مفتاح مفتوح (تسرب مهمل)
- المنحنى I-V: الكفة الأمامية (بعده يرتفع التيار انفجارياً) + انهيار عكسي (avalanche).

## 3) التقويم
| النوع | ديودات | Vdc | تردد التموج | PIV للديود |
|---|---|---|---|---|
| نصف موجة | 1 | `Vm/π ≈ 0.318Vm` | f | Vm |
| موجة كاملة (جسر 4 ديودات) | 4 | `2Vm/π ≈ 0.637Vm` | 2f | Vm |
| موجة كاملة بمحول بوسطي | 2 | `2Vm/π` | 2f | 2Vm |

- مع مكثف تنعيم: `Vripple ≈ IL/(2fC)` (كاملة) — C أكبر ← تموج أقل.

## 4) الزينر — تثبيت الجهد
- يعمل في **المنطقة العكسية** عند جهد الانهيار Vz ثابتاً
- المقاوم الواقي: **`Rs = (Vin − Vz)/(Iz + IL)`**
- شروط العمل: Vin > Vz دائماً + `Iz` ضمن (Iz,min حتى Iz,max).

## 5) الترانزسستور BJT
- العلاقات: `Ie = Ib + Ic` — `α = Ic/Ie` (≈1) — **`β = Ic/Ib`** (50–300 نموذجياً)
- المناطق: قطع (كلا الوصلات عكسية — مفتاح مفتوح) / نشطة (أمامية انبعاث، عكسية تجميع — **ضخم**) / تشبع (كلاهما أمامية — مفتاح مغلق، Vce ≈ 0.2V)
- تحيز ثابت: `Ib = (Vcc − Vbe)/Rb` — `Ic = β·Ib` — `Vce = Vcc − Ic·Rc`
- خط الحمل: `Vce = Vcc − Ic(Rc + Re)` — طرفا الخط: Ic,sat و Vce,off
- تحيز مقسم الجهد (الأثبت حرارياً): `VB = Vcc·R₂/(R₁+R₂)`، `Ve = VB − 0.7`، `Ie = Ve/Re`.

## 6) JFET
- `Id = Idss(1 − Vgs/Vp)²` (معادلة شوكلي — Vp جهد القطع)
- المناطق: أومية / قطع (pinch-off) / `Vgs = Vp` ← Id = 0
- التحكم **بجهد** المدخل (مقاومة دخول عالية جداً) — عكس BJT (تحكم بتيار).

## 7) مكبر العمليات Op-Amp
- القاعدتان الذهبيتان (المثالي): تيارا المدخل = 0، و `V+ = V−` (في التغذية الراجعة السالبة)
- عاكس: **`Av = −Rf/Rin`** | غير عاكس: **`Av = 1 + Rf/R1`**
- جامع: `Vo = −(Rf/R1·V1 + Rf/R2·V2 + ...)`
- تابع: `Av = 1` | مقارن: يعمل بلا تغذية راجعة — Vo ±Vsat
- المازج/المفاضل: `Vo = −(1/jωC)∫... ` (تكاملي) و `−R·C·dVin/dt` (تفاضلي).

## 8) القدرة والكفاءة في المكبرات
- كفاءة الصنف A: ≤ 25% (بمقاومة) / 50% (بمحول) — الصنف B: حتى 78.5% — AB حل وسط.

### ✔ أنماط تحقق سريعة
- Rs لزينر 9V من مصدر 15V على 20mA+5mA: `bun calc.mjs eval "(15-9)/(0.02+0.005)"` ← 240Ω
- Vdc لموجة كاملة بقمم 12V: `bun calc.mjs eval "2*12/3.14159"` ← 7.64V
- تحيز ثابت: Vcc=12, Rb=470k, β=100: `bun calc.mjs eval "(12-0.7)/470000*100"` ← 2.4mA = Ic
