## نقاط النهاية المجرَّبة
| Endpoint | Method | ملاحظات |
|---|---|---|
| `/health` | GET | **بدون توكن** — status, tool_count, uptime, license, fingerprint |
| `/mcp` | POST | JSON-RPC 2.0 — `tools/call` بالتوكن Bearer |
| `/tools` | GET | قائمة كل الأدوات مع danger_level (30MB!) |
| `/dashboard` | GET | واجهة ويب بالتوكن |
| `/execute`, `/execute/stream`, `/batch`, `/workflow` | POST | بديلة لـ /mcp |

## نموذج الاستدعاء المجرَّب
```bash
curl -X POST https://<tunnel>.trycloudflare.com/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <توكن-المتمم — في الخزنة>" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"file_list","arguments":{"path":"C:\\\\path"}}}'
```
- الرد: `result.content[0].text` = JSON نصي (يفك بـ json.loads مرتين)
- الأخطاء الدلالية تأتي داخل result بنجاح isError — اقرأ `error`/`isError`

## أدوات الملفات (المستخدمة فعلياً)
| أداة | dl | بارامترات | استخدامها |
|---|---|---|---|
| `file_list` | 1 | path | عرض مجلد — يعيد name/is_dir/size_bytes |
| `file_read_text` | 1 | path, max_bytes? | قراءة نصية |
| `file_read_bytes` | 1 | path | قراءة base64 (تحقق SHA256) |
| `code_write_file` | 1 | path, content, create_backup? | كتابة نص + **إنشاء المجلدات الأب تلقائياً** |
| `file_upload` | 1 | source_url, dest_path, overwrite, timeout_seconds (10-3600) | **تنزيل URL → مسار محلي** (مفتاح نقل الثنائيات) |
| `file_write` | 2 | path, content, encoding?, append? | محجوبة: تأكيد إلزامي |
| `dir_mkdir` | 2 | path, parents, exist_ok | محجوبة: تأكيد إلزامي |
| `code_run_python` | 3 | code | محجوبة عبر النفق (localhost only) |
| `tool_execute` | 1 | name, args | جسر لأداة أخرى — **لا يتجاوز** حواجز dl2 |

## دروس مؤلمة (لا تُكرر)
1. DPoP/OAuth/`/auth/token` مع النفق = طريق مسدود — `missing_token: DPoP required` على بعض الendpoints يضلل — Bearer على /mcp يعمل مباشرة
2. `encoding: "base64"` في file_write غير موجود عملياً (وتؤكَّد الحاجة لأداة ثنائية — file_upload هو الحل)
3. الرفع الخلفي (nohup/setsid) في بيئة المساعد لا ينجو بين استدعاءات Bash — التنفيذ الأمامي على دفعات بميزانية زمنية أضمن
4. HEAD على x0.at يرجع 404 دائماً — التحقق بـ GET فعلي أو Content-Length في الرد
5. سلسلة تحقق كاملة: SHA256 محلياً → رفع → GET تنزيل → مقارنة → نقل للجهاز → file_list مقارنة حجم — كلها نجحت 33/33
